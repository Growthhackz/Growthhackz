Settings

Every trade is simulated first: a swap that would fail is not sent, and the compute limit is set from the simulation, so the priority fee is paid on what the swap uses.

Rules

Buys and sells are independent. Each rule fires on a price level or a schedule (1 minute and up). Price rules fire once, or every time price crosses the level if “repeat” is on. Prices are in SOL per token, read from this wallet's pool. A token can have scheduled buys or scheduled sells, not both at once.

Activity —

    Emergency stop —

    • Turns automation off and disables every rule
    • Sells all tokens to SOL (at least 5% slippage)
    • Unwraps wSOL and closes token accounts to reclaim rent

    Clone —

    Copies the venue, pool, token, slippage, fee settings, SOL floor and all rules. Keys and balances stay with each wallet. Copies start paused; switch them on when funded.

    Copy onto existing wallets

    Their current settings and rules are replaced.
